# Security policy

Flectar Mail Sync is in early development and has no stable release yet.

## Reporting a vulnerability

Email [hello@flectar.com](mailto:hello@flectar.com) with the subject "Flectar
Mail Sync security report". Please do not disclose vulnerabilities in public
issues, discussions or pull requests before a fix can be coordinated.

Include, where possible:
- the affected commit or image tag
- what an attacker could do, and what they need first
- steps to reproduce, using test data only

Reports may cover the protocol and cryptography (`docs/SPEC.md`), the server,
the crates, and the container image.
